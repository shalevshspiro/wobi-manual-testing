# Wobi - Manual QA Testing Project

## Project Overview

This repository presents a manual QA project performed on the **Wobi insurance website**.

The project focused on evaluating real user flows and product quality through structured manual testing. The work included **STR, STD, test execution, and bug analysis**, with emphasis on functional behavior, usability, validation, and compatibility.

The published portfolio artifact in this repository is the final **STR (Software Test Report)**.

## Testing Scope

The project covered manual testing areas such as:

- Functional testing
- UI and UX testing
- Web and mobile testing
- Compatibility and cross-browser testing
- Navigation and user-flow validation
- Form and input validation
- Negative testing
- Regression and retesting where relevant
- Exploratory testing

## Test Environment

The project included coverage of both **web and mobile contexts**.

Browser, device, and execution-environment details are documented in the STR report so that the test results can be evaluated together with the environment in which they were produced.

## QA Process

1. Reviewed the product and identified important user flows.
2. Designed structured test scenarios and STD test cases.
3. Executed manual tests and documented expected vs. actual behavior.
4. Recorded defects and analyzed their impact.
5. Used severity and priority to support risk assessment.
6. Performed retesting where relevant.
7. Consolidated the execution results, defect analysis, and conclusions into the STR.

## Tools & Methodologies

- **TestRail** - test management
- **Jira** - defect reporting and tracking

## Test Results

The testing process identified functional, UI/UX, validation, and user-flow issues that were documented and analyzed as part of the QA process.

The full execution status, detailed findings, and supporting evidence are available in the STR report.
